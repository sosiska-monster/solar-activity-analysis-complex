# Программный комплекс для анализа солнечной активности по фотографиям 🌞

Автоматизированная информационная система (АС) серверной аналитики астрономических изображений Солнца. Программный комплекс разработан на базе высокопроизводительного веб-фреймворка **FastAPI** и предназначен для автоматического расчёта индексов солнечной активности (чисел Вольфа), математической кластеризации групп пятен, трекинга их смещения с учётом дифференциального вращения Солнца, а также де-ротации по суточному параллельному дрейфу.

---

## 🔬 Физико-математический базис и алгоритмы

Комплекс автоматизирует рутинные астрофизические вычисления, используя методы компьютерного зрения и пространственно-временного анализа:

1. **Сегментация солнечного диска и фильтрация ROI:**
   * Автоматическое определение контуров диска на основе бинаризации Оцу (`cv2.THRESH_OTSU`) и аппроксимации минимальной описывающей окружности (`cv2.minEnclosingCircle`).
   * Динамическое масштабирование и нормализация контраста для устранения эффекта потемнения диска к краю (Limb Darkening).
2. **Расчёт чисел Вольфа ($W = 10g + s$):**
   * Локальная адаптивная фильтрация для детекции ядер (полутеней и теней пятен).
   * **SciPy Кластеризация:** Группировка изолированных солнечных пятен ($s$) в физические группы ($g$) по модифицированному Цюрихскому методу классификации с использованием иерархической кластеризации (`scipy.cluster.hierarchy.linkage`) по пространственному расстоянию (в угловых градусах).
3. **Физический трекинг дифференциального вращения:**
   * Проекция двумерных координат пикселей ($x, y$) на сферическую модель Солнца.
   * Моделирование угловой скорости вращения в зависимости от гелиографической широты ($\phi$) по эмпирической зависимости:
     $$\omega(\phi) = 14.713 - 2.396 \cdot \sin^2(\phi) - 1.787 \cdot \sin^4(\phi)$$
   * Пространственный поиск парных пятен на разновременных кадрах с помощью KD-деревьев (`scipy.spatial.KDTree`) для построения непрерывных траекторий (треков) эволюции активности.
4. **Вычисление суточного параллельного дрейфа:**
   * Анализ серии снимков с отключенным часовым ведением телескопа для точного определения угла наклона оси камеры относительно небесного экватора через тригонометрический расчёт вектора смещения центра диска.

## 🏗 Архитектура проекта

Приложение спроектировано в соответствии с принципами разделения ответственности (Separation of Powers) и Clean Architecture:

```text
├── app/
│   ├── __init__.py
│   ├── api.py                  # HTTP-контроллеры, валидация входящих схем, роутинг FastAPI
│   ├── auth.py                 # Слой безопасности: Zero-Trust Bearer Token авторизация
│   ├── database.py             # Инфраструктурный слой: ThreadedConnectionPool для PostgreSQL
│   ├── processing/
│   │   ├── image_core.py       # Низкоуровневая обработка изображений, парсинг EXIF метаданных (Pillow)
│   │   ├── sunspots.py         # Алгоритмы компьютерного зрения OpenCV, детекция пятен и расчёт метрик
│   │   └── tracking.py         # Математические модели физики Солнца, предикция координат, KDTree-поиск
│   └── utils/
│       └── logger.py           # Модуль системного аудита (Audit Trail) действий пользователей в БД
├── Dockerfile                  # Изолированная многослойная сборка среды исполнения (Python-slim)
├── docker-compose.yml          # Оркестрация сервисов бэкенда и реляционной СУБД PostgreSQL
├── main.py                     # Точка входа для запуска ASGI-сервера Uvicorn
├── requirements.txt            # Стабилизированные и вычищенные зависимости проекта
└── .env.example                # Шаблон конфигурации переменных окружения
